# 蛙声跳跳

基于 ESP32-C3 AI Passport 的离线应用，使用重新设计的池塘界面。按住 OK
说话，松开后得到 **0～100 分**的随机趣味评分，像素青蛙按分数高低跳跃。
实现将“调高”理解为调整跳跃高度。不进行语音识别、语义评价、云端通信、
语音存储或回放。

## 操作与行为

| 操作 | 行为 |
| --- | --- |
| 按住 OK | 以 16 kHz、单声道、16 位采集麦克风 PCM，显示时长和实时音量条。 |
| 松开 OK | 结束采集，550 毫秒后显示随机分数，播放 1.1 秒跳跃动画。 |
| 落地后按上键 | 按同一个分数重播跳跃。 |
| 非录音时按下键 | 回到待机画面，保留本次开机的最高分。 |

单次录音最多 10 秒，到时自动结束；需要先松开按键才能开始下一次。
按住不足 400 毫秒或采样不足 3,200 点不评分。简单静音判断要求至少有
640 个采样点来自峰峰值达到 300 的音频块；静音或仅有直流偏移会提示重试。
它不是真正的语音检测，需要实机验证灵敏度；背景噪声也可能满足条件。
评分独立随机生成，与音量、时长、内容无关。

0 分时青蛙留在荷叶上，100 分最高跳离固定基线 88 像素，整个轨迹保持在
屏幕内。当前分数和最高分仅存于 RAM，重启清零。音频故障丢弃本轮结果，
松开后再按住 OK 可重试。电量不可用时显示 `--%`。

无操作 45 秒后背光降到 12%，120 秒后熄屏；音频芯片成功暂停后，任务以
100 毫秒定时唤醒的方式进入短时 light sleep。按住 OK 唤醒并说话；休眠时
极短的点击可能漏检。功耗和 USB 休眠行为需要实机测量。不引入猜测的 GPIO
唤醒接线，也不使用不可逆的 deep sleep 外设关断序列。

## 实现与资源

应用直接启动 `main/frog_ui.c` 的新界面，基线菜单/demo 源码仅作参考，未编入
本应用。硬件操作复用 BSP。按键 API 追加 `BSP_BTN_RELEASE` 松开事件，保留
此前枚举数值。按键回调只覆盖最新状态邮箱，不会因事件队列满而卡在录音中。
一个常驻任务独占模型、音频和电量读写；所有 UI 调用持有 LVGL 锁。没有需要
销毁的临时页面或 UI 定时器。录音仅使用 640 字节 PCM 块，不按说话时长分配
大缓冲区。工作任务栈为 6,144 字节。LVGL 使用共享 C 堆，BSP 原有的单个
240×40 RGB565 DMA 缓冲区保持不变。蓝牙已禁用。

中文使用 Noto Sans CJK SC 的 14／20 像素、4 bpp、无压缩字体子集，覆盖全部
固定文案及可打印 ASCII。大分数字体为 Montserrat 36。界面不显示识别结果或
用户自定义文本。可复现生成方式与许可见[字体资源说明](../assets/README.zh_CN.md#蛙声跳跳字体)。
运行时启动和主机模拟器都检查字符描述符，包含已知缺字的反向测试；模拟器
还检查每个实际标签选用的字体及布局边界。

## 复现验证

激活 ESP-IDF **5.5.3**，使用安装时对应的 Python。本次 macOS 环境使用
Python 3.13，避免误激活 3.14 的虚拟环境。

```sh
./tools/validate.sh --static
./tools/validate.sh
```

完整验证使用独立的配置和构建目录，从受版本控制的默认配置编译；在主机上
运行实际 LVGL 9.5 应用界面，校验合并镜像并归档匹配的 ELF／MAP／镜像。
Managed Components 下载完成后，也可独立执行模拟器：

```sh
./tools/test_frog_ui.sh
```

打开 `build/preview/index.html` 查看实际 LVGL 生成的待机、录音、蓄力、
0／50／100 分跳跃、落地及全部错误状态。运行的是固件的界面和模型代码，
硬件驱动没有在主机上运行。测试覆盖全部 101 种分数、边界、时序、静音与
直流偏移、最长录音、重试、重播、归位、时间回绕、动画边界、字体清单与
源文件身份、BSP 松开事件注册和失败回滚，以及原项目主机测试。
渲染还执行 20 次完整跳跃轨迹。主机验证不能证明电气行为、实际调度和屏幕效果。

交付的合并固件为 `build/FoloToy-AI-Passport-full.bin`，从 **0x0** 刷写。
内容寻址归档位于 `build/firmware/<sha256>/`，含对应 ELF／MAP 和
`manifest.json`。使用前执行
`python3 tools/archive_firmware.py verify <bundle-directory>` 校验。
默认 8 MB 分区布局未改变。合并刷写可能重置 NVS 和已有设置；如需保留，
必须采用分区兼容的分段刷写方案。刷机需要用户明确确认；验证流程不执行
擦除或烧录命令。

## 仍需实机验收

- 冷启动、重启和供电变化；全部状态中文、颜色、裁剪、电量与 100 分布局。
- 按住与松开响应、快速按键、长时间按住、多键、连续多轮、麦克风音量与
  静音阈值、麦克风故障恢复。
- 0／50／100 分对应跳跃高度；主机快照已确定性覆盖，正常固件保持随机评分。
- 音频与显示同时运行的稳定性、最低空闲堆／最大连续块、栈余量及至少 100 轮测试。
- 背光变暗与熄屏、按住唤醒、唤醒后录音、USB 重新枚举和实际电流。
  软件暂停成功不能代表外部功放的实际耗电。

授权烧录前，设备测试应标为 **NOT RUN**，上述项目标为未验证；构建和主机
测试分别报告。
